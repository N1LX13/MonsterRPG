# MonsterRPG
A compact monster-catching RPG featuring 16 unique monsters, experience (XP) progression, and simple turn-based combat. Designed to be small and approachable while offering room for strategy and growth.

## Features
- 16 distinct monsters with varying stats and rarities
- XP-based leveling system for monsters and the player
- Turn-based battles with basic skills and status effects
- Capture mechanic with a chance system influenced by monster HP and rarity
- Save/load support (simple file-based saves)

## Gameplay (brief)
- Explore locations, encounter wild monsters, and fight or attempt to capture them.
- Winning battles grants XP; monsters and the player level up to improve stats.
- Captures depend on monster HP and rarity — weaken foes without knocking them out.

## Quick start
1. Clone the repo
2. Run the game executable or start the main script
3. Follow on-screen prompts to create a player and begin your adventure

## Extending the game
- Add new monsters by editing the monsters data file (name, base stats, rarity)
- Implement new skills or status effects in the combat system
- Improve AI or add more locations and events
